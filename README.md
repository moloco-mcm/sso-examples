# SSO Examples

Examples of generating signed SSO URLs to use the embedded RMP Campaign Manager.

## Structure

This repository contains SSO examples in multiple programming languages. The top-level language directories always contain the **latest version** of the examples.

```
sso-examples/
├── golang/          # Latest example (currently v1.1.0)
├── java/            # Latest example (currently v1.1.0)
├── node/            # Latest example (currently v1.1.0)
├── ruby/            # Latest example (currently v1.1.0)
└── versions/        # Previous versions
    └── v1.0.0/      # Version 1.0.0 examples
        ├── golang/
        ├── java/
        ├── node/
        └── ruby/
```

## Available Languages

- **Golang** - `golang/example.go`
- **Java** - `java/EmbeddedCampaignManagerExample.java`
- **Node.js** - `node/example.js`
- **Ruby** - `ruby/example.rb`

## Versioning

- **Latest examples**: Check the top-level language directories
- **Previous versions**: Check the `versions/` directory for archived examples
